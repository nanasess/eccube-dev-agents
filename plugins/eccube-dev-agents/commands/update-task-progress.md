# タスクコマンドの進捗更新

このコマンドは、`.claude/commands/active/` に保存されているタスクコマンドファイルの進捗状況を更新します。

## 概要

実行中のタスクコマンドファイルを特定し、会話内容やgit diff、テスト結果から完了状況を判定して、チェックボックスやステータスを自動更新します。

## 手順

1. **対象ファイルの特定**:
   - `$ARGUMENTS` が指定されている場合:
     - ファイル名のみの場合: `.claude/commands/active/<ファイル名>` を検索
     - `archive` 指定の場合: 完了したタスクを `archive/` に移動
   - `$ARGUMENTS` がない場合:
     - `.claude/commands/active/` ディレクトリから `*.md` ファイルを検索
     - 最も新しく更新されたファイルを使用
     - 複数見つかった場合: 一覧表示して選択を促す

2. **現在の進捗状況を解析**:
   - ファイル内の進捗テーブルを読み込み
   - チェックボックス（`- [ ]` / `- [x]`）の状態を確認
   - 各フェーズのステータス（⏳ 未着手 / 🔄 進行中 / ✅ 完了）を確認

3. **完了状況の判定**:
   以下の情報源から完了したタスクを特定:

   a. **会話内容から判定**:
      - 最近の会話で「完了」「実装した」「修正した」などの表現を検出
      - 対応するタスクを完了としてマーク

   b. **git diff から判定**:
      - `git diff --name-only` で変更されたファイルを確認
      - タスクに関連するファイルが変更されていれば完了候補

   c. **テスト結果から判定**:
      - テストが通過していれば関連タスクを完了候補

   d. **手動確認**:
      - 自動判定できない場合はユーザーに確認を求める

4. **ファイルを更新**:
   - 完了したタスクのチェックボックスを `[x]` に変更
   - 進捗テーブルのステータスを更新:
     - `⏳ 未着手` → `🔄 進行中` → `✅ 完了`
   - 最終更新日時を追記

5. **更新結果を報告**:
   - 更新前後の進捗率
   - 今回完了としてマークした項目
   - 残りの未完了項目
   - 次に取り組むべきタスクの提案

## 引数

`$ARGUMENTS` (オプション):
- ファイル名（例: `issue-572-implement.md`）
- `archive` - 完了したタスクを archive/ に移動
- `archive <ファイル名>` - 指定したタスクを archive/ に移動

## 使用例

```bash
# 最新のタスクファイルを自動検出して更新
/update-task-progress

# 特定のファイルを指定して更新
/update-task-progress issue-572-implement.md

# 完了したタスクを archive/ に移動
/update-task-progress archive issue-572-implement.md
```

## 更新の例

### 更新前:

```markdown
## 進捗状況

| Phase | 状態 | 説明 |
|-------|------|------|
| Phase 1 | ✅ 完了 | モデル定義の修正 |
| Phase 2 | 🔄 進行中 | リポジトリの更新 |
| Phase 3 | ⏳ 未着手 | テストの追加 |

### `phase2` - Phase 2 の実行

- [x] タスク 2.1: OrderRepository の修正
- [ ] タスク 2.2: ProductRepository の修正
- [ ] タスク 2.3: CustomerRepository の修正
```

### 更新後:

```markdown
## 進捗状況

| Phase | 状態 | 説明 |
|-------|------|------|
| Phase 1 | ✅ 完了 | モデル定義の修正 |
| Phase 2 | ✅ 完了 | リポジトリの更新 |
| Phase 3 | 🔄 進行中 | テストの追加 |

### `phase2` - Phase 2 の実行

- [x] タスク 2.1: OrderRepository の修正
- [x] タスク 2.2: ProductRepository の修正
- [x] タスク 2.3: CustomerRepository の修正

<!-- 最終更新: 2026-01-15 18:00 -->
```

## アーカイブ機能

タスクが完全に完了したら、`archive` 引数を使用して `archive/` ディレクトリに移動できます:

```bash
/update-task-progress archive issue-572-implement.md
```

これにより:
- ファイルが `.claude/commands/active/` から `.claude/commands/archive/` に移動
- ファイル名に日付プレフィックスが追加（例: `2026-01-issue-572-implement.md`）
- アーカイブ後も `/archive:2026-01-issue-572-implement` で参照可能

## 注意事項

- 自動判定の精度には限界があるため、重要なタスクは手動確認を推奨
- git の変更がコミットされていない場合、判定が不正確になる可能性があります
- 複数人で作業している場合は、競合を避けるため更新前に最新状態を確認してください
